# BAZA-R-COM: интернет-магазин, сделанный с ИИ

Сайт магазина мотозапчастей: каталог, карточки товаров, корзина и оформление заказа, оплата через Т-Банк, заказы в Telegram, все страницы, которые нужны банку для эквайринга.

## Из чего состоит

```
public/            ← всё, что видит покупатель
  index.html       главная: каталог, корзина, оформление
  products.json    ТОВАРЫ (цены, описания, фото, наличие)
  store.json       МАГАЗИН (контакты, реквизиты, доставка)
  img/             фото товаров
  dostavka-i-oplata.html, vozvrat.html, oferta.html,
  politika.html, soglasie.html, kontakty.html   ← страницы для банка
server.js          сервер: заказ → оплата Т-Банк → сообщение в Telegram
CLAUDE.md          инструкция для агента правок
.env.example       образец настроек (ключи бота и банка)
```

Главная мысль для эфира: **весь магазин — это фото и два файла**, `products.json` и `store.json`. Агент правок меняет только их.

## Этапы (порядок для эфира)

### Этап 0. Что собрать у селлера заранее
- Фото и описания товаров (уже есть), **цены**.
- ИП/ООО: ФИО или название, ИНН, ОГРНИП, адрес регистрации.
- Расчётный счёт в Т-Банке (есть) и система налогообложения + НДС (для чеков).
- Контакты для сайта: телефон, Telegram, почта, город, часы работы, самовывоз.
- Доставка: службы, сроки, стоимость. Возврат и гарантия своими словами.
- Домен (покупает сам на reg.ru, ~200 ₽/год).

### Этап 1. Сайт из фото и описаний — делает ИИ
Показываем: кидаем Claude папку с фото и текстами, просим сделать интернет-магазин. Получаем каталог, карточки, корзину, страницы доставки, возврата, оферты и политики.
Жёлтым подсвечено всё, что ещё не заполнено, — наглядно, что спросить у селлера.

### Этап 2. Домен
Покупка домена на reg.ru. Дальше в настройках домена (DNS) нужно будет прописать адрес хостинга — это этап 4.

### Этап 3. GitHub — где хранится сайт
Бесплатный аккаунт на github.com, новый **приватный** репозиторий, туда загружаем папку проекта. Зачем: хостинг сам берёт сайт отсюда, а агент правок вносит изменения сюда.

### Этап 4. Хостинг и публикация на свой домен
Нужен хостинг, который:
- запускает Node.js (сервер нужен для оплаты и бота);
- сам обновляет сайт при изменениях в GitHub;
- стоит в России (персональные данные покупателей по закону хранятся в РФ) и платный (банки не любят бесплатный хостинг);
- даёт бесплатный SSL (замочек https).

Берём обычный облачный сервер (Timeweb Cloud → «Облачные серверы», Москва, Ubuntu 24.04, 1 ядро, 1 ГБ) и запускаем на нём от root одну команду:
```
curl -fsSL https://raw.githubusercontent.com/ЛОГИН/baza-r-com/main/deploy/setup-shop.sh \
  | bash -s -- baza-r-com.ru https://github.com/ЛОГИН/baza-r-com.git
```
Скрипт ставит Node.js и Caddy (https), скачивает сайт в `/opt/shop`, включает автозапуск (`systemctl restart shop`) и каждые 2 минуты забирает изменения из GitHub. Затем в reg.ru две A-записи (`@` и `www`) на IP сервера. Ключи бота и банка — в `/opt/shop/.env`.

Агент правок ставится на второй сервер (Амстердам/Франкфурт, 1 ядро, 2 ГБ) скриптом `deploy/setup-agent.sh` — см. этап 6 и презентацию.

### Этап 5. Бот для заказов (агент №2)
1. В Telegram написать @BotFather → `/newbot` → получить токен.
2. Создать группу «Заказы BAZA-R-COM», добавить туда бота, написать любое сообщение.
3. Вписать токен в `TELEGRAM_BOT_TOKEN` и перезапустить приложение.
4. Открыть `https://ваш-домен/api/telegram-chat-id`, скопировать id группы в `TELEGRAM_CHAT_ID`, перезапустить.
5. Оформить тестовый заказ на сайте — сообщение приходит в группу.
Кто будет обрабатывать заказы, селлер решит сам: просто добавит людей в группу.

Что приходит:
- 🆕 новый заказ: товары, сумма, контакты, адрес (сразу при оформлении);
- ✅ «Оплачен заказ №…» — когда Т-Банк подтвердил оплату;
- ❌ оплата не прошла — можно перезвонить покупателю.

Проверить, что всё подключено: `https://ваш-домен/api/health`.

### Этап 6. Агент правок (агент №1)
Агент — это Claude Code на зарубежном сервере, вошедший в подписку селлера (Claude Pro), с официальным плагином Telegram. Он читает `CLAUDE.md` и знает, где что лежит; разрешения — в `.claude/settings.json`.
```
curl -fsSL https://raw.githubusercontent.com/ЛОГИН/baza-r-com/main/deploy/setup-agent.sh \
  | bash -s -- https://github.com/ЛОГИН/baza-r-com.git ТОКЕН_GITHUB
su - agent && cd ~/baza-r-com && claude      # вход в аккаунт Claude
/plugin install telegram@claude-plugins-official
/telegram:configure ТОКЕН_БОТА_ПОМОЩНИКА
/exit, exit, затем: agent-start
# написать боту → /telegram:access pair КОД → /telegram:access policy allowlist → Ctrl+B, D
```
Пишем ему обычными словами:
- «Скрой карбюратор, он закончился»
- «Поставь на цепь цену 2900, старую зачеркни»
- «Добавь товар: звезда 48 зубьев, 1500 ₽, вот фото»
- «Поменяй телефон на +7 …»

Агент правит файл, проверяет, публикует в GitHub, хостинг обновляет сайт через 1–2 минуты.

### Этап 7. Эквайринг Т-Банка и чеки
1. Сайт уже опубликован на домене, все страницы заполнены, демо-плашки нет (`"demo": false` в `store.json`), цены настоящие.
2. В личном кабинете Т-Бизнес подать заявку на интернет-эквайринг, указать адрес сайта. Там же подключить «Чеки от Т-Кассы» (облачная касса: без неё чек покупателю не уйдёт, а по 54-ФЗ он обязателен).
3. Банк проверяет сайт. До одобрения можно работать с **тестовым терминалом**: оплата проходит по тестовым картам, деньги не списываются.
4. После одобрения взять в кабинете TerminalKey и пароль терминала → `TBANK_TERMINAL_KEY`, `TBANK_PASSWORD`. В настройках терминала указать уведомления «по HTTP» на адрес `https://ваш-домен/api/tbank-notify`.
5. Проверить у бухгалтера и в кабинете: система налогообложения (`TAXATION`), ставка НДС в чеке (`VAT`), версия ФФД кассы (`FFD_VERSION`).
6. Тестовая покупка: заказ → страница оплаты Т-Банка → чек на почту → «✅ Оплачен» в Telegram.

Пока ключей банка нет, сайт всё равно принимает заказы: они приходят в Telegram с пометкой «ожидает оплаты», оплату можно согласовать с покупателем вручную.

## Как запустить у себя на компьютере
Нужен Node.js 18+.
```
cp .env.example .env     # вписать ключи (можно оставить пустыми)
node server.js           # сайт откроется на http://localhost:3000
```
Без ключей сайт работает полностью, заказы печатаются в консоль.

## Перед запуском в работу
- Тексты оферты, политики и согласия — шаблоны. Показать юристу.
- Подать уведомление в Роскомнадзор об обработке персональных данных (обязательно для всех, кто собирает данные покупателей).
- Заменить все жёлтые места в `store.json`.
