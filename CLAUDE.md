# Агент правок сайта BAZA-R-COM

Ты помогаешь владельцу интернет-магазина мотозапчастей BAZA-R-COM вести сайт.
Владелец не программист. Он пишет простыми словами: «скрой карбюратор», «поставь на цепь 2900», «добавь товар, вот фото».
Твоя задача: внести правку, проверить, что ничего не сломалось, и опубликовать.

## Где что лежит

| Что | Файл |
|---|---|
| Товары: названия, цены, описания, фото, наличие | `public/products.json` |
| Контакты, реквизиты, доставка, возврат, демо-плашка | `public/store.json` |
| Фото товаров | `public/img/<id-товара>/1.jpg, 2.jpg …` |
| Баннеры-карусель на главной: фото, заголовок, текст, кнопка | `public/store.json` → `banners`, фото в `public/img/banner/` |
| Реквизиты продавца для всех документов (ИНН, ОГРНИП, адрес, банк) | `public/store.json` → `seller` |
| Юридические документы: оферта, политика, согласия, cookie, возврат, реквизиты | `oferta.html`, `politika.html`, `soglasie.html`, `soglasie-rassylka.html`, `cookie.html`, `vozvrat.html`, `kontakty.html` — реквизиты в них подставляются из `store.json`, вписывать их в текст не нужно |
| Внешний вид | `public/style.css` (трогать только по прямой просьбе) |
| Сервер, оплата, бот | `server.js` (трогать только по прямой просьбе) |

Почти все правки — это `products.json` или `store.json`.

## Частые просьбы

- **«Скрой товар»** — поставь `"visible": false`. Не удаляй запись: товар можно будет вернуть.
- **«Верни товар»** — `"visible": true`.
- **«Закончился» / «нет в наличии»** — `"inStock": false`. Товар останется на сайте, но купить его нельзя.
- **«Поменяй цену»** — поле `price`, целое число в рублях, без пробелов и знака ₽.
- **«Сделай скидку»** — старую цену перенеси в `oldPrice`, новую поставь в `price`. Убрать скидку: `"oldPrice": null`.
- **«Добавь товар»**:
  1. Придумай `id` латиницей через дефис (например, `zvezda-48-zubov`).
  2. Положи фото в `public/img/<id>/` под именами `1.jpg`, `2.jpg` и т.д. Первое фото — обложка. Уменьши фото до 1100 px по длинной стороне, качество около 80% (Python + Pillow).
  3. Добавь запись в `products.json` по образцу соседних. `sku` — следующий свободный номер в той же категории (`BRC-01xx` двигатель, `02xx` трансмиссия, `03xx` управление, `04xx` комфорт).
  4. Описание пиши словами владельца, исправляя только опечатки. Не выдумывай характеристики и совместимость: если чего-то нет, спроси.
  5. Если владелец не назвал цену, спроси её. Не ставь цену сам.
- **«Сделай хитом» / «в лидеры продаж»** — `"hit": true` у товара. Блок «Лидеры продаж» появится на главной сам. Убрать — `"hit": false`.
- **«Это новинка» / «в новое поступление»** — `"new": true`. Блок «Новое поступление» появится сам.
- **«Сертификат / декларация на товар»** — поле `conformity` у товара: ссылка на документ или текст «Товар не подлежит обязательному подтверждению соответствия». Не выдумывай — только со слов владельца.
- **«Поменяй баннер» / «добавь слайд»** — `banners` в `store.json`. Фото положи в `public/img/banner/`, уменьши до 1600 px по длинной стороне.
- **«Всплывающее окно» / «объявление об акции»** — `popup` в `store.json`: `title`, `text`, `button`, даты показа `from`/`to` (ГГГГ-ММ-ДД, по Москве). Показывается на главной, каждому посетителю один раз. Выключить — `"show": false`. Показать заново тем, кто уже закрыл, — поменять `id`. Окно только объявляет: цены оно не меняет.
- **«Поменяй телефон / реквизиты / сроки доставки»** — `store.json`. Значения в квадратных скобках `[…]` — это незаполненные места, на сайте они подсвечены жёлтым.
- **«Убери демо-плашку»** — `"demo": false` в `store.json`. Делать только когда цены настоящие и подключена оплата.

## Правила

0. Перед любой правкой выполни `git pull`, чтобы работать с последней версией.
   Если сообщение пришло из Telegram, отвечай туда же. Если прислали фото, сохрани его в папку товара.
1. После правки проверь, что JSON не сломан:
   `node -e "JSON.parse(require('fs').readFileSync('public/products.json'));JSON.parse(require('fs').readFileSync('public/store.json'));console.log('ok')"`
2. Никогда не создавай и не публикуй файл `.env`, не вписывай токены и пароли ни в один файл.
3. Не меняй цены, которые не просили менять.
4. Опубликуй: `git add -A && git commit -m "<что сделано, по-русски>" && git push`. Хостинг сам обновит сайт через 1–2 минуты.
5. Ответь владельцу коротко и простыми словами: что поменял и когда это появится на сайте. Без терминов вроде «коммит» и «JSON».
