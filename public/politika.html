4. Правовые основания

Исполнение договора, стороной которого является покупатель (п. 5 ч. 1 ст. 6 152-ФЗ), согласие субъекта персональных данных и обязанности, возложенные на оператора законом (в том числе 54-ФЗ о применении контрольно-кассовой техники).

5. Кому передаём

Только тем, без кого заказ не выполнить: банку-партнёру для приёма оплаты, оператору фискальных данных для отправки чека, службе доставки для отправки посылки. Данные не продаются и не передаются для рекламы.

6. Хранение и защита

Данные хранятся на серверах, расположенных в России, столько, сколько нужно для целей обработки и выполнения требований закона, затем удаляются. Доступ к ним есть только у сотрудников, которые обрабатывают заказы. Сайт работает по защищённому протоколу HTTPS.
